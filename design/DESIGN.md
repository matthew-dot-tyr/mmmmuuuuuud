# АРЕНА ПЕРЕГОВОРОВ — фронтенд: дизайн и работа с API

Эталон внешнего вида — `design/mockups.html` (открыть в браузере). Фронт повторяет его: цвета, шрифты, скругления, объёмные кнопки, маскота. Поведение и данные — по разделу «API» ниже и по `README.md` бэкенда. Рабочий пример клиента для сверки — `static/play.html` (там, например, `renderFeedback`).

## Шрифты (Google Fonts)
- **Nunito** 800/900 — заголовки, кнопки, цифры, подписи капсом (letter-spacing .06–.1em)
- **Rubik** 400/500 — обычный текст и реплики

## Правила стиля
- **Объёмная кнопка:** `border-radius:16px; box-shadow:0 5px 0 <тёмный оттенок>`; `:active` → `transform:translateY(5px); box-shadow:none`. Текст капсом, Nunito 900.
- Тот же приём (рамка 2px + нижняя тень 3–4px) у плиток тем, карточек сложности, вариантов ответа. Выбранное — рамка/тень `--primary`, фон `--primary-light`.
- Скругления: кнопки 16px, карточки 18–24px, теги 999px. Рамки 2px `--line`.
- Полоса XP: 16px, скругление 999px, заливка `--xp`.
- Мобильная вёрстка в первую очередь (макеты — экран телефона), на десктопе колонка ~420px по центру.
- `prefers-reduced-motion` отключает конфетти и анимации.

## Маскот — енот Торг
SVG-функция `raccoon(mood, size, tie, cheer)` в конце `mockups.html` — перенести как компонент.
`happy` — ведущий, сложность 1, победа · `stubborn` — сложность 2 · `sly` — сложность 3 · `tie` — галстук (роль начальника) · `cheer` — лапы вверх при победе.

## Экраны
1. **Вход** — только email и кнопка «Получить ссылку». Вход по magic link: `supabase.auth.signInWithOtp({ email, options:{ emailRedirectTo: <адрес фронта> } })`. После отправки — состояние «Проверь почту». Пароля и отдельной регистрации нет.
2. **Профиль бойца** — уровень в звезде (1–3), стрик 🔥 из `/streak`, полоса XP до следующего уровня (на 3-м уровне вместо полосы — «Максимальный уровень»), кнопка «На арену», «Последние бои» из `/attempts` (показать 3–5 штук; пусто — скрыть блок).
3. **Подготовка** — 4 темы + «Своя ситуация» (textarea, 30–400 символов, счётчик символов). Сложность 1–3: «Хочет договориться» / «Держит позиции» / «Стоит насмерть». Недоступные (нет в `unlocked_difficulties`) — серые, пунктир, 🔒 «с N уровня», не кликаются. Кнопка «В бой».
4. **Арена** — сверху соперник (`counterpart_role`, теги `counterpart_tone` и «Цель: `counterpart_goal`»), под ним свёрнутая карточка «Ситуация» (`scenario_text`). Диалог: соперник слева белым, игрок справа `--primary`. Первая реплика — `counterpart_opening`. Внизу: на сложности 1–2 варианты `options` + «Ответить»; на 3 — поле ввода (до 2000 символов). «Ход N» — просто номер, лимита нет. Пока ждём ответ — «Торг думает…» (печатающие точки), кнопки заблокированы.
5. **Итог** — `outcome: "success"` → «ПОБЕДА!» на `--win-light` с конфетти; иначе «ПОРАЖЕНИЕ» на `--lose-light`, грустный енот. Плашки Опыт `+xp_gained` / Оценка `score/10` (только при победе) / Соперник (перчики). Разбор судьи из `feedback`. Если `level_up: true` — золотой баннер «Новый уровень N! Открыта сложность …», иначе анимированная полоса XP. «Продолжить» → профиль.

## Прогресс (как считает бэкенд, фронт только показывает)
- Уровни 1–3, по умолчанию 100 XP на уровень: 0–99 → 1, 100–199 → 2, 200+ → 3 (максимум).
- Сложность N открыта с уровня N.
- XP: поражение 5; победа `score × {1: 5, 2: 8, 3: 12}[сложность]`.

## API (FastAPI, базовый URL — переменная окружения фронта)
Все запросы кроме `/` — с заголовком `Authorization: Bearer <access_token>` из `supabase.auth.getSession()`. На `401` — выход и экран входа.

| Запрос | Когда | Ответ |
|---|---|---|
| `POST /user` | сразу после входа (создаёт профиль, если нет) | `UserResponse` |
| `GET /user/me` | профиль, подготовка | `user_id, xp, level, xp_to_next_level, unlocked_difficulties[]` |
| `GET /streak` | профиль | `streak_count, last_practiced_date` |
| `GET /attempts` | профиль | до 20 × `{id, theme (слаг или null), level (=сложность), success, score, created_at}` |
| `POST /negotiation/start` | «В бой» | см. ниже |
| `POST /negotiation/turn` | каждый ответ | см. ниже |

**start**, тело: `{ "mode":"theme", "theme":"work|money|purchase|personal", "difficulty":1 }` или `{ "mode":"custom", "custom_situation":"…", "difficulty":1 }`.
Ответ: `negotiation_id, session_token, scenario_text, counterpart_opening, counterpart_role, counterpart_tone, counterpart_goal, options?` (`options` = `[{option_id:"a", text}]`, нет на сложности 3).
Отказ приходит **с кодом 200**: `{ rejected:true, reason, message }` — показать `message` под полем своей ситуации (или тостом), не переходить на арену.

**turn**, тело: `{ session_token, option_id }` (сложность 1–2) или `{ session_token, message }` (3). `session_token` — непрозрачная строка: всегда отправлять последний полученный.
- `continue:true` → `counterpart_reply, session_token, options?` — добавить реплику, обновить токен и варианты.
- `continue:false` → `counterpart_reply, outcome, score, feedback, xp_gained, xp, level, level_up` — показать последнюю реплику, затем экран итога.

**feedback** — объект `{broke_quote, broke_reason, what_worked, alternative_phrasing, tip}` (заполнен всегда только `tip`, остальное может быть `null` — пустые пункты не показывать) **или строка**, если модель не собрала структуру. Проверять тип. Подписи: «Где сломалось» (`broke_quote` цитатой + `broke_reason`), «Что сработало», «Можно было сказать так», «Совет».

**Ошибки:** `403` — сложность закрыта / чужие переговоры; `409` — бой уже засчитан (просто перейти в профиль); `503` — «ИИ временно недоступен» + кнопка «Повторить» (повторить тот же запрос с тем же токеном); `400/422` — показать `detail`. Тексты ошибок — дружелюбные, от лица енота.

## Настройка окружения
- Фронту нужны `SUPABASE_URL`, `SUPABASE_ANON_KEY` (публичный anon-ключ, НЕ service key из `.env` бэкенда) и `API_URL`.
- В Supabase: Authentication → URL Configuration → Redirect URLs — добавить адрес фронта.
- В `.env` бэкенда: `CORS_ORIGINS` — адрес фронта.
